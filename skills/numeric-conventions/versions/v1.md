# Numeric conventions

- Percentages to one decimal place. RULE:PCT_ONE_DECIMAL
- Confidence intervals to one decimal place, formatted "95% CI: lower, upper".
- Never report a percentage for a denominator below 20; report n only.
- In-text values must be identical to the source TLF cell; never re-round.
- Dates in text use "DD Month YYYY" (e.g. 01 May 2026).
